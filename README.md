# 极简阅读器 (ai_book_reader)

Python tkinter 实现的轻量 TXT 小说阅读器，支持无边框置顶、窗口透明度、自动隐藏、全局快捷键和代码风格主题。基于 Python 标准库，无需额外运行依赖。

## 功能

- 加载 TXT 文件，**自动识别编码**（UTF-8 / UTF-8-BOM / UTF-16 / GB18030，告别乱码）
- **章节自动识别**（第 X 章/节/回/卷…）+ 章节列表选择、上一章 / 下一章
- **字体大小**调节（A+/A- 按钮）
- **窗口透明度**调节（滑块，0.15~1.0，整窗连续变化）
- **自定义字体颜色**（字色按钮，调色板选择）
- **自定义背景颜色**（底色按钮，调色板选择）
- **无边框** + 置顶 + 不显示在任务栏
- **鼠标移出窗口即自动隐藏**（400ms 延时防误触）
- **全局快捷键**：Ctrl+` 唤出/隐藏（窗口隐藏后也能调回）
- **老板键**：Ctrl+Shift+H 一键隐藏
- **伪装成代码编辑器**（VS Code 风格标签栏 + 行号 + 状态栏 + `//` 注释配色）
- **阅读进度记忆**：每本书自动记住上次读到哪
- 窗口位置 / 大小 / 主题 / 设置全部记忆
- **沉浸模式**：双击正文隐藏所有工具栏，纯文字阅读

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + ` ` ` (反引号) | 唤出 / 隐藏窗口（全局） |
| `F9` | 备用唤出 / 隐藏（全局，单键更方便） |
| `Ctrl + Shift + H` | 老板键，瞬间隐藏 |
| `Ctrl + Shift + Q` | 退出程序 |
| `F11` 或双击正文 | 切换沉浸/伪装阅读模式 |
| `Ctrl + ← / →` | 上一章 / 下一章 |

## 使用

需要 Python 3.8+（本机已装 3.14.3，自带 tkinter，无需 pip install 任何包）。

### 下载 Windows 版

[前往 GitHub Releases 下载最新 exe](https://github.com/Douidol/win_book_reader/releases/latest)，Windows 版无需单独安装 Python。

此 exe 未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示；请确认文件来自本项目 Release 后再运行。

### 双击启动

直接双击 **`启动py.bat`**。

### 命令行启动

```bash
python main.py
```

首次启动会弹出文件选择框，选 `sample-小说.txt` 或你自己的 TXT 小说。

## 操作说明

- **打开文件**：点 📂 按钮，或首次启动自动弹出选择框
- **章节选择**：点 📑 按钮，弹出章节列表，点击章节标题跳转
- **切换章节**：使用底部“上一章 / 下一章”按钮，或按 `Ctrl + ← / →`
- **字号**：A-/A+ 按钮
- **窗口透明度**：◐ 滑块，往左拉可降低整个窗口的不透明度
- **字体颜色**：字 按钮（显示当前颜色），点击弹出调色板
- **背景颜色**：底 按钮（显示当前颜色），点击弹出调色板
- **主题**：🎨 按钮循环切换 深色 → 浅色 → 伪装代码 → 自定义
- **固定**：📌 按钮暂停自动隐藏（调设置时好用）
- **沉浸/伪装阅读**：⛶ 按钮或 F11 或双击正文；沉浸模式下可按 `Ctrl + ← / →`，或滚到章节边界后继续滚动切章
  - 普通主题：隐藏所有工具栏，纯文字阅读
  - 代码主题：隐藏工具栏，**保留 IDE 标签栏 + 状态栏**，看起来就是在 VS Code 里看代码注释，伪装更逼真
- **移动窗口**：拖动顶部彩色细条
- **调整大小**：拖动正文右下角的斜纹角标，或右键切换尺寸预设
- **隐藏**：— 按钮或鼠标移出窗口或 Ctrl+`
- **退出**：✕ 按钮或 Ctrl+Shift+Q

## 摸鱼建议

- 把窗口拖到屏幕角落、调低透明度，看起来像便签/代码片段
- 用"伪装代码"主题，远看就是 VS Code 里的一段注释
- 老板走近：直接 Ctrl+Shift+H，或把鼠标往旁边一甩

## 技术说明

- 全局快捷键通过 Win32 `RegisterHotKey` + 后台线程实现，无需安装第三方库
- 编码识别：BOM 检测 → UTF-8 严格 → GB18030 回退
- 透明度使用 tkinter `-alpha` 属性（整窗口半透明）
- 窗口无边框使用 `overrideredirect(True)`，不显示在任务栏
- 状态和进度保存在 `app-data/` 目录

## 打包成 exe（无需 Python 环境）

exe 通过 GitHub Release 单独发布，源码仓库不存放打包产物。也可以按以下步骤自行生成：

```bash
# 安装打包工具（仅开发时需要）
pip install -r requirements.txt

# 打包成单文件 exe
python -m PyInstaller --onefile --windowed --name "极简阅读器" --distpath . --workpath build --specpath build --noconfirm main.py
```

生成的 `极简阅读器.exe` 位于项目根目录。
